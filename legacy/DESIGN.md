# 제주 레저 활동 도구 설계서

대주제: **서핑** (윈드서핑 · 패러글라이딩 포함)
목표: "어디서 / 지금 바람이 어떤지 / 해도 되는지"를 판단하고, 주변 편의 정보(맛집 · 카페 · 샤워장 · 관광지)와 지도까지 한 번에 제공한다.

## 1. 전체 흐름

```
list_sites ──▶ get_wind_gusts ──▶ judge_activity ──▶ (가능) 주변 정보 조회 ──▶ 지도 저장
 장소 목록      풍속·돌풍·파고       가능/주의/불가       맛집·카페·샤워장·관광지     jeju_activity_map.html
```

## 2. 도구 목록

### 2.1 핵심 도구

| 도구 | 입력 | 출력 | 데이터 출처 |
|---|---|---|---|
| `list_sites(activity)` | `surfing` · `windsurfing` · `paragliding` · 생략(전체) | 장소 id, 이름, 좌표, 해변 방향, 설명 | `sites.py` 정적 목록 |
| `get_wind_gusts(site_id)` | 장소 id | 풍속, 돌풍, 돌풍 편차, 풍향, 오프쇼어 여부, 파고, 파주기, 수온, 기온, 강수 | Open-Meteo Forecast + Marine |
| `judge_activity(site_id, conditions?)` | 장소 id (조건값을 직접 넣을 수도 있음) | `status`(가능/주의/불가), `reasons`, `tips`, 사용한 조건값 | 아래 3장 기준표 |

### 2.2 부가 도구 (요청하신 API 추가분)

| 구분 | 도구 | 사용 API | 키 |
|---|---|---|---|
| 지도 | `map_link(site_id)` | OpenStreetMap 링크 | 불필요 |
| 지도 | `save_map(...)` | Leaflet + OpenStreetMap (HTML 생성) | 불필요 |
| 날씨 | `get_weather(site_id)` | Open-Meteo Forecast | 불필요 |
| 해변 | `list_beaches()` | 한국관광공사 TourAPI `KorService2/searchKeyword2` (keyword=해수욕장, areaCode=39) | 필요 |
| 맛집 | `find_restaurants(site_id)` | TourAPI 위치기반 조회 `locationBasedList2` (contentTypeId=39, 카페 제외) | 필요 (공공데이터포털) |
| 카페 | `find_cafes(site_id)` | TourAPI 위치기반 조회 (contentTypeId=39, cat3=A05020900) | 필요 (공공데이터포털) |
| 관광지 | `find_attractions(site_id)` | TourAPI 위치기반 조회 (contentTypeId=12) | 필요 (공공데이터포털) |
| 공용샤워실 | `find_showers(site_id)` | OpenStreetMap Overpass API (`amenity=shower`) | 불필요 |

키가 없거나 인터넷이 끊기면 모든 도구는 **샘플 데이터**(`source: "sample"`)를 돌려주므로, 수업 중에도 프로그램이 멈추지 않는다.

## 3. 판정 기준 (judge_activity)

단위: 풍속·돌풍 m/s, 파고 m. 위에서부터 검사하며, **불가 → 주의 → 가능** 순으로 처음 걸리는 단계가 결과가 된다. 뇌우(천둥·번개)가 있으면 모든 활동이 **불가**다.

| 활동 | 불가 | 주의 | 가능 |
|---|---|---|---|
| 서핑 | 풍속 ≥ 11 · 돌풍 ≥ 14 · 파고 ≥ 3.0 | 풍속 ≥ 7 · 돌풍 ≥ 10 · 파고 ≥ 2.0 · 파고 < 0.3 | 그 외 |
| 윈드서핑 | 풍속 ≥ 14 · 돌풍 ≥ 17 | 풍속 ≥ 10 · 돌풍 ≥ 13 · 돌풍 편차 ≥ 5 · 풍속 < 3(바람 부족) | 대략 3~10 m/s |
| 패러글라이딩 | 풍속 ≥ 8 · 돌풍 ≥ 10 · 돌풍 편차 ≥ 5 · 강수 > 0.5mm | 풍속 ≥ 5.5 · 돌풍 ≥ 8 · 돌풍 편차 ≥ 3.5 | 그 외 |

- **돌풍 편차** = 돌풍 − 평균 풍속. 값이 클수록 바람이 들쭉날쭉해 난기류 위험이 크다(특히 패러글라이딩).
- **오프쇼어**: 바람이 육지에서 바다 쪽으로 불면 파도 면이 정돈되어 서핑에 유리하다. `sites.py`의 해변 방향(`facing_deg`)과 풍향으로 계산한다.
- 위 수치는 **초보자 기준의 학습용 예시값**이다. 실제 운영 기준은 업체·강사·기상특보를 따르며, `tools.py`의 `RULES`만 고치면 바뀐다.

## 4. 장소 데이터 (sites.py)

| 활동 | 장소 |
|---|---|
| 서핑 | 중문색달, 이호테우, 곽지, 월정리, 하도 |
| 윈드서핑 | 신양섭지코지, 김녕 |
| 패러글라이딩 | 금오름 이륙장 |

좌표는 대략적인 값이다. 장소를 추가하려면 `SITES`에 한 줄을 넣으면 된다.

## 5. 확장 후보 (공공데이터)

| API | 활용 방법 |
|---|---|
| 국립해양조사원 서핑지수 조회 (data.go.kr 15142490) | 판정에 공식 서핑지수(5단계)를 함께 표시 |
| 국립해양조사원 이안류 지수 조회 (data.go.kr 15156028) | 이안류 '경계·위험'이면 서핑 불가로 상향 |
| 기상청 전국 해수욕장 날씨 조회서비스 (data.go.kr 15102239) | 국내 공식 예보로 Open-Meteo 값을 교차 확인 |
| 기상청 단기예보 (VilageFcstInfoService_2.0) | 국내 예보 풍속(WSD). 돌풍 값은 제공되지 않아 Open-Meteo와 병행 |

## 6. 주의사항

- 공용 샤워장은 해수욕장 개장 기간(주로 여름)에만 운영되는 경우가 많다. 그 외 기간에는 서핑숍 샤워실(강습·대여 고객용)을 확인한다.
- TourAPI 위치기반 조회의 `radius`는 최대 20,000m이며, 관광공사에 등록된 장소만 나온다.
- OpenStreetMap은 한국 샤워장 등록이 적어 결과가 비는 경우가 많다. 이때는 서핑숍 샤워실을 안내한다.
- 카카오 API는 사용하지 않는다. 공공데이터포털 키 하나로 맛집·카페·관광지·해변까지 조회한다.
- TourAPI는 2025년부터 `KorService2`로 바뀌었다. 파라미터가 달라지면 공공데이터포털 문서를 확인한다.
